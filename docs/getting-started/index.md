# Getting started

Pick one tutorial: each blinks an LED on a PIC16F877A, first in the simulator with no hardware and then on a real chip. They need no Microchip download.

- **[Command line](cli.md):** compile with epic-cc and build with epic-hal's Makefiles. Choose this if you like `make` and a terminal.
- **[PlatformIO](platformio.md):** add the epic8 platform to a `platformio.ini`. Choose this if you already use PlatformIO or want `pio run`.

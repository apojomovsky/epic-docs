# Guides

Short how-to pages for a hobbyist who finished [Getting started](../getting-started/index.md). Each one uses a PIC16F877A and code from a tested epic-hal file.

- [Drive and read pins](gpio.md): outputs, toggling and button inputs.
- [Timers and interrupts](timers-interrupts.md): the 1 ms timebase and a Timer0 callback.
- [Send and receive over UART](uart.md): print to your computer and echo input back.

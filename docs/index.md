# epic8 documentation

epic8 is a fully open source, MIT licensed toolchain, HAL and
PlatformIO platform for 8-bit PIC microcontrollers.

## The family

| Repository | What it is |
|---|---|
| [epic-cc](https://github.com/apojomovsky/epic-cc) | The C compiler |
| [epic-hal](https://github.com/apojomovsky/epic-hal) | The hardware abstraction layer |
| [epic-platformio](https://github.com/apojomovsky/epic-platformio) | The PlatformIO platform |
| [epic-tools](https://github.com/apojomovsky/epic-tools) | Programmers and tooling |

## Ways to use epic8

Use the command line and Make with `epic-cc` directly, or use the
complete PlatformIO path with `epic-platformio`. Both build the same
programs; pick the one that fits how you work.
